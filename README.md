Job Portal UI
A modern and responsive Job Portal UI built using React.js.
This project displays beautifully designed job cards with company logos, job details, salary information, and quick apply actions.
Features
  -Responsive Job Cards
  -Dynamic Data Rendering
  -Company Logos
  -Job Type & Experience Tags
  -Salary & Location Display
  -Apply Now Button
Tech Stack
  -React.js
  -JavaScript
  -CSS
